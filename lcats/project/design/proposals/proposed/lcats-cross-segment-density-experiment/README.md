# Cross-Segment Density Experiment Delivery

This proposal set records the staged design for turning the existing
cross-segment relation density pilot into a defensible, auditable,
cost-bounded Worldcon-scale experiment. It treats `WI-EVENT-0030` as the
near-final empirical run, not as the first action after planning.

- [`00_proposal.md`](00_proposal.md) - background, prior-art check, design
  decisions, non-goals, and implementation plan.
