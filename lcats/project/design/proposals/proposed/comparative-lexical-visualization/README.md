# Comparative Lexical Visualization and Rich Linguistic Annotations

This proposal set records the design for reproducible lexical comparisons
across LCATS corpora and subcorpora, including mirrored, reference-overlay,
and aligned multi-subset figures. It also defines the rich-token and derived
lexical artifacts needed for stopword, lemma, and POS-aware comparisons.
