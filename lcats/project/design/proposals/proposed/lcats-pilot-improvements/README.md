# Stabilized, User-Facing ERW Pilot Improvements

This proposal set records the design for a follow-on
`WS-PILOT-IMPROVEMENTS` workstream after
`PROP-LCATS-PILOT-COST-SUSTAINABILITY`: stabilize the real ERW pilot API and
output path first, then adopt the measured prompt-caching, model-tiering, and
Batch API improvements behind explicit quality and spend gates.

## Documents

- [`00_proposal.md`](00_proposal.md) — background, prior-art check, five
  design decisions, non-goals, and an ordered implementation plan.

Governed by the proposed `WS-PILOT-IMPROVEMENTS` workstream to be created
after this proposal is adopted.
