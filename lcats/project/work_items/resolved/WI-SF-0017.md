# Work Item: WI-SF-0017

## Summary

Harden the local Ollama/OpenAI-compatible structured-output path for Knight and Suvin analysis, then rerun the bounded two-story contract canary with persisted diagnostics.

## Problem / Context

The completed `WI-SF-0015` canary exposed a local-model integration failure in shared evidence extraction. The local model produced malformed nested tool-call JSON that the provider rejected with `unexpected end of JSON input`; the positive control also completed with Knight `0/0` and no qualified Novum. The canary report therefore recommends a local-model-specific response-format or repair path, a regression fixture for the observed malformed response, and another two-story local canary before any larger local run.

This item is a focused operational follow-up to `WI-SF-0013` and `WI-SF-0014`. It does not reopen the Knight or Suvin theoretical definitions and does not block the separately authorized staged Opus paper-data run.

### Duplication search

- In-repo: Related implementation exists in `experimental/science_fiction_analysis_trial/run_worldcon_spike.py`, the science-fiction contract modules, and resolved `WI-SF-0013`/`WI-SF-0014`; no existing unresolved item covers this specific post-canary local structured-output fix.
- Sibling repos: None identified.
- External libraries: No external library identified that can safely repair LCATS-specific evidence, anchors, and theory-neutral contract records without project-specific validation.
- Recommendation: Proceed by extending the existing runner and contract-validation paths rather than creating a parallel local-model pipeline.

### Demand search

- Work items: `WI-SF-0015` records this exact follow-up demand in its canary report; `WI-SF-0013` and `WI-SF-0014` are completed prerequisites rather than duplicates.
- Proposals: The adopted Knight/Novum proposal requires strict structured outputs, deterministic validation, quarantine, and partial-success behavior.
- Backlog: No separate matching local science-fiction structured-output hardening entry found.
- Recommendation: Link this item to `WI-SF-0015` and the existing workstream; do not close or rewrite the completed items.

## Scope

- Reproduce and classify the observed local malformed/truncated evidence tool-call response.
- Add a narrowly bounded local response-format, normalization, or repair path that never invents missing evidence.
- Add no-cost regression coverage for recoverable and unsafe malformed outputs.
- Rerun the existing two-story local contract canary once after the fix, preserving all outputs.

## Required Changes

1. Inspect the persisted `WI-SF-0015` raw response, backend-error, quarantine, and run-log artifacts and encode the observed failure shape as a deterministic fixture.
2. Update the local evidence-stage boundary in `experimental/science_fiction_analysis_trial/run_worldcon_spike.py` or the appropriate shared science-fiction/LLM boundary so that:
   - valid structured output continues normally;
   - safely recoverable structural damage is normalized deterministically;
   - malformed output requiring semantic invention is quarantined;
   - no missing quote, paragraph anchor, evidence identity, or analytical judgment is fabricated.
3. Preserve and expose failure classification, retry accounting, raw response paths, and quarantine paths for every failed attempt.
4. Add focused tests under `tests/analysis_tests/science_fiction/` for:
   - the captured truncated nested evidence response;
   - safe quarantine of unrecoverable output;
   - bounded retry accounting;
   - valid evidence-reference handling;
   - preservation of partial success;
   - rejection of silent success from malformed output.
5. Update `experimental/science_fiction_analysis_trial/contract_canary_runbook.md` with the post-fix local-canary command and inspection checklist.
6. Rerun the exact two-story `contract_canary_manifest.json` against the local model using a new experiment-local output root.
7. Update `experimental/science_fiction_analysis_trial/contract_canary_report.md` with the new trial result, structural outcomes, positive/negative behavior, failures, latency, token usage, and proceed/revise/stop recommendation.
8. Do not run paid models, the local 10-story sample, or the 146-story sample as part of this item.

- Raw model output, backend errors, retry events, and quarantine records are persisted for every attempted failure.
- The post-fix two-story local canary produces interpretable positive/negative results, or stops with complete persisted diagnostics and an explicit revise/stop recommendation.
- The report distinguishes structural pipeline health from theoretical validity and does not overclaim what the canary demonstrates.
