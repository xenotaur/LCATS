# Work Item: WI-SF-0005

## Summary

Implement pure-Python validation, checkpoint reuse, and deterministic assembly for a single append-oriented `science-fiction.json` sidecar.

## Problem / Context

The proposal requires one versioned `science-fiction.json` sidecar containing shared evidence and independently versioned Knight and Novum analyses (`project/design/proposals/adopted/knight-novum-analysis-sidecar/00_proposal.md:268`). LCATS already has checkpoint utilities with atomic writes (`src/lcats/utils/checkpoint.py:302`) and a validator-only `genre-sidecar-v1` pattern (`src/lcats/analysis/corpus/genre_sidecar.py:1`), so this item should extend those patterns without changing production annotation or promotion behavior.

### Duplication search
- In-repo: No science-fiction sidecar validator or checkpointed assembler exists. Genre sidecar validation and checkpoint utilities are related patterns.
- Sibling repos: None identified.
- External libraries: No production JSON Schema dependency is justified solely for Phase 1.
- Recommendation: Proceed after dependencies.

### Demand search
- Work items: No existing WI implements science-fiction sidecar assembly.
- Proposals: `PROP-LCATS-KNIGHT-NOVUM-ANALYSIS-SIDECAR` requests this as Phase 1E.
- Backlog: No matching backlog entry found.
- Recommendation: Link to `WS-KNIGHT-NOVUM-ANALYSIS`.

## Scope

- Validate typed records structurally and semantically in Python.
- Check referential integrity, story hashes, current pointers, validation outcomes, and partial success.
- Fingerprint effective inputs and reuse/rematerialize per-stage checkpoints.
- Publish validated experiment-local `science-fiction.json` files atomically.

## Required Changes

1. Create `src/lcats/analysis/science_fiction/sidecar.py` with validation helpers.
2. Create `src/lcats/analysis/science_fiction/pipeline.py` for checkpointed assembly and rematerialization.
3. Integrate existing LCATS checkpoint and atomic-write patterns where they fit.
4. Add tests for valid sidecars, invalid references, stale hashes, invalid current pointers, checkpoint reuse, rematerialization, interrupted stages, partial Knight/Novum success, and byte-stable output with nondeterministic fields fixed.

## Non-Goals

- Do not introduce a production JSON Schema dependency solely for Phase 1.
- Do not write to `corpora/`, alter corpus promotion, or change production annotation commands.
- Do not make paid model calls.

## Acceptance Criteria

- Pure-Python validation checks structure, semantics, references, story hashes, current pointers, and partial-success invariants.
- Versioned fingerprints cover all effective inputs needed for checkpoint reuse and rematerialization decisions.
- Per-stage checkpoint reuse and atomic single-writer `science-fiction.json` assembly are tested.
- Validated output contains shared evidence plus independently versioned Knight and Novum analyses.
