# Work Item: WI-SF-0006

## Summary

Build an experiment-local runner and no-cost fixture suite for the science-fiction analysis pipeline.

## Problem / Context

Phase 1 must remain experiment-local while supporting dry runs, cost estimates, checkpoint reuse, and no-cost fixtures before any pilot or paid model call (`project/design/proposals/adopted/knight-novum-analysis-sidecar/00_proposal.md:466`). Existing annotation and promotion behavior must remain untouched until a later integration gate.

### Duplication search
- In-repo: No science-fiction experiment runner exists.
- Sibling repos: None identified.
- External libraries: None replace the LCATS-specific runner and fixtures.
- Recommendation: Proceed after `WI-SF-0005`.

### Demand search
- Work items: No existing WI implements this runner.
- Proposals: `PROP-LCATS-KNIGHT-NOVUM-ANALYSIS-SIDECAR` requests this as Phase 1F.
- Backlog: No matching backlog entry found.
- Recommendation: Link to `WS-KNIGHT-NOVUM-ANALYSIS`.

## Scope

- Provide a deterministic experiment-local CLI or script with no-cost fixture mode and dry-run cost estimation.
- Support resume, checkpoint reuse, bounded retries and concurrency, and explicit output roots.
- Add fixtures covering the required science-fiction, non-novum, ambiguous, malformed, stale, interrupted, overlap, and partial-success cases.

## Required Changes

1. Create `experimental/science_fiction_analysis_trial/README.md`.
2. Create `experimental/science_fiction_analysis_trial/run_trial.py` or an equivalent experiment-local runner.
3. Create `experimental/science_fiction_analysis_trial/fixtures/` with deterministic fixture inputs and expected outputs.
4. Add tests for dry-run behavior, no-cost fixture mode, cost-estimate gating, output-root safeguards, resume, checkpoint reuse, bounded retry/concurrency settings, and fixture coverage.

## Non-Goals

- Do not run Phase 2 or Phase 3 pilots.
- Do not make paid model calls without a reviewed manifest, estimated budget, pinned configuration, and explicit approval.
- Do not write to corpus or production promotion paths.
- Do not modify `lcats annotate` or `lcats promote`.

## Acceptance Criteria

- Experiment-local runner supports deterministic manifests, `--dry-run`, cost estimation, no-cost fixture mode, resume, checkpoint reuse, bounded retries, bounded concurrency, and explicit output roots.
- Runner safeguards prevent writes to corpus or production promotion paths.
- Fixture and unit coverage includes the proposal's required positive, negative, ambiguous, malformed, stale-hash, interrupted, partial-success, overlap, and byte-stability cases.
- No paid calls are possible without a reviewed manifest, estimated budget, pinned configuration, and explicit approval.

## Validation

## Dependencies / Order

This depends on `WI-SF-0005`, because the runner needs validated sidecar assembly and checkpoint semantics before it can be meaningful.
