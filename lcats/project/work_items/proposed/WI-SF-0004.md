# Work Item: WI-SF-0004

## Summary

Implement separate Knight and Suvin adjudication modules that consume shared evidence while keeping their theoretical judgments, failure modes, and deterministic calculations independent.

## Problem / Context

The proposal explicitly rejects a combined genre probability and requires Knight's framework to remain seven independently evidenced criteria with deterministic `definite_count` and `possible_count` intervals (`project/design/proposals/adopted/knight-novum-analysis-sidecar/00_proposal.md:241`). It also requires Suvinian novum qualification to be conjunctive across novelty, cognitive validation, and narrative hegemony, with estrangement recorded separately (`project/design/proposals/adopted/knight-novum-analysis-sidecar/00_proposal.md:147`).

### Duplication search
- In-repo: No Knight or Suvin adjudicator exists.
- Sibling repos: None identified.
- External libraries: None replace source-governed literary adjudication.
- Recommendation: Proceed after dependencies.

### Demand search
- Work items: No existing WI implements these adjudicators.
- Proposals: `PROP-LCATS-KNIGHT-NOVUM-ANALYSIS-SIDECAR` requests this as Phase 1D.
- Backlog: No matching backlog entry found.
- Recommendation: Link to `WS-KNIGHT-NOVUM-ANALYSIS`.

## Scope

- Implement Knight criterion adjudication and deterministic interval calculation.
- Implement Suvin candidate identification, N/C/H adjudication, dominant novum, and novum-system validation.
- Support bounded theory-specific follow-up retrieval when shared evidence is insufficient.
- Represent explicit `absent`, `ambiguous`, `not_assessable`, and pipeline-failure states.

## Required Changes

1. Create `src/lcats/analysis/science_fiction/knight.py` for Knight criterion adjudication and deterministic interval calculations.
2. Create `src/lcats/analysis/science_fiction/novum.py` for Suvin candidate, N/C/H, estrangement, dominant novum, and system decisions.
3. Ensure one analysis can succeed, partially succeed, or fail without forcing the same outcome on the other.
4. Add tests for seven independent Knight criteria, no threshold/probability, Suvin conjunction, no additive score, estrangement separation, ambiguous and not-assessable states, and partial Knight/Novum success.

## Non-Goals

- Do not combine Knight and Suvin into one model call or one final probability.
- Do not invent a Knight pass threshold.
- Do not replace Suvin's conjunction with compensatory scoring.
- Do not make paid model calls or write corpus sidecars.

## Acceptance Criteria

- Knight adjudication records seven independently evidenced criteria and deterministic `definite_count` and `possible_count` intervals.
- Suvin adjudication qualifies novum candidates only through conjunctive novelty, cognitive validation, and narrative hegemony.
- Estrangement is recorded separately from novum qualification and character surprise is optional evidence.
- Knight analysis can complete when Suvin fails and Suvin analysis can complete when Knight fails.
