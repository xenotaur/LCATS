# Work Item: WI-SF-0001

## Summary

Define the versioned data contracts for the Knight/Novum science-fiction analysis sidecar, including the Knight seven-feature profile, Suvin novum records, shared evidence records, provenance, validation, and partial-success envelopes.

## Problem / Context

`PROP-LCATS-KNIGHT-NOVUM-ANALYSIS-SIDECAR` requires a shared, theory-neutral evidence layer and independently versioned Knight and Suvin analyses before runtime extraction or adjudication can be implemented (`project/design/proposals/adopted/knight-novum-analysis-sidecar/00_proposal.md:26`). The proposal also says Knight's seven descriptions and Suvin's theoretical definitions must not be frozen from memory or secondary summaries; exact governing text, edition, and page citations must be supplied before source-dependent rubric implementation is finalized (`project/design/proposals/adopted/knight-novum-analysis-sidecar/00_proposal.md:120`).

### Duplication search
- In-repo: No existing Knight/Suvin contract package, `science-fiction.json` validator, or science-fiction sidecar was found. Related substrate exists in `src/lcats/analysis/corpus/genre_sidecar.py` and should be extended as a pattern, not duplicated wholesale.
- Sibling repos: None identified.
- External libraries: None replaces the LCATS-specific literary contracts; production JSON Schema is not required for Phase 1.
- Recommendation: Proceed.

### Demand search
- Work items: No existing WI provides these contracts.
- Proposals: `PROP-LCATS-KNIGHT-NOVUM-ANALYSIS-SIDECAR` requests this work as Phase 1A.
- Backlog: No matching backlog entry found.
- Recommendation: Link to `WS-KNIGHT-NOVUM-ANALYSIS`.

## Scope

- Define versioned Python records for shared evidence, Knight adjudication, Suvin novum adjudication, sidecar envelope metadata, provenance, validation, failure, and partial success.
- Encode deterministic contract rules such as Knight `definite_count`/`possible_count` intervals and conjunctive Suvin novelty/cognition/hegemony decisions.
- Preserve source-dependent rubric text as pending until primary-source excerpts or approved repository sources are provided.

## Required Changes

1. Create `src/lcats/analysis/science_fiction/models.py` and supporting package files for versioned contract records.
2. Create `src/lcats/analysis/science_fiction/rubric/` records or documentation for `knight-seven-v1` and `suvin-novum-v1`, with source-dependent text explicitly marked unresolved if primary-source excerpts are not supplied.
3. Add no-cost tests under `tests/analysis_tests/science_fiction/` for contract construction, invalid states, deterministic Knight intervals, Suvin conjunction, estrangement separation, current pointers, partial-success records, and validation errors.
4. Keep all contracts experiment-local and independent of corpus promotion behavior.

## Non-Goals

- Do not implement evidence extraction, adjudication prompts, orchestration, experiment runners, or pilots.
- Do not make paid model calls.
- Do not freeze Knight or Suvin theoretical wording from memory or secondary summaries.
- Do not modify `lcats annotate`, `lcats promote`, `data/`, or `corpora/`.

## Acceptance Criteria

- `knight-seven-v1`, `suvin-novum-v1`, neutral evidence, anchoring, provenance, failure, validation, and `science-fiction-sidecar-v1` contracts are represented as versioned Python data records.
- Tests cover Knight states, deterministic count intervals, Novum N/C/H conjunction, estrangement separation, partial success, current pointers, and validation failures.
- Source-dependent Knight and Suvin rubric wording remains explicitly blocked unless authoritative sources are supplied.
- No runtime runner, paid model call, corpus write, annotate change, or promote change is included.
