# Work Item: WI-SF-0003

## Summary

Implement backend-independent interfaces and validation logic for extracting shared, theory-neutral evidence used by both Knight and Suvin analysis.

## Problem / Context

The proposal requires a neutral evidence layer before any theory-specific adjudication, with evidence such as storyworld changes, explanations, inquiry methods, displacement, extrapolation, catastrophes, reactions, and reader-facing contrasts (`project/design/proposals/adopted/knight-novum-analysis-sidecar/00_proposal.md:224`). ERW work supplies adjacent spans and `anomaly_or_novum` hypotheses, but the proposal keeps ERW optional so this item must not require an ERW run (`project/design/proposals/adopted/lcats-event-role-world-extractor/00_proposal.md:185`).

### Duplication search
- In-repo: No Knight/Novum shared evidence interface exists. ERW evidence spans are adjacent and optional, not a duplicate.
- Sibling repos: None identified.
- External libraries: None replace the LCATS-specific anchored evidence records.
- Recommendation: Proceed.

### Demand search
- Work items: No existing WI implements this neutral layer.
- Proposals: `PROP-LCATS-KNIGHT-NOVUM-ANALYSIS-SIDECAR` requests this as Phase 1C.
- Backlog: No matching backlog entry found.
- Recommendation: Link to `WS-KNIGHT-NOVUM-ANALYSIS` and ERW prior art.

## Scope

- Define extraction interfaces and strict structured records for neutral evidence categories.
- Locate exact quotations deterministically against `WI-SF-0002` story anchors.
- Quarantine malformed or unlocatable evidence while preserving extraction provenance.
- Support optional ERW evidence adaptation without making ERW a prerequisite.

## Required Changes

1. Create `src/lcats/analysis/science_fiction/evidence.py` with backend-independent request/response records and validators.
2. Implement deterministic quotation location and anchor binding using prepared paragraph IDs.
3. Implement overlap de-duplication that preserves conflicts and records provenance.
4. Add optional adapter boundaries for ERW-derived spans without importing ERW as a required runtime stage.
5. Add tests for valid evidence, unlocatable quotations, overlap duplicates, conflicting chunk outputs, ERW absence, and provenance preservation.

## Non-Goals

- Do not adjudicate Knight criteria or Suvin N/C/H decisions.
- Do not combine theoretical judgments into a single model decision.
- Do not require ERW or scene/sequel output.
- Do not make paid model calls or write corpus sidecars.

## Acceptance Criteria

- Backend-independent extraction interfaces and strict structured output records cover the proposal's shared neutral evidence categories.
- Exact quotations are deterministically located against stable anchors and invalid evidence is quarantined.
- Overlap de-duplication preserves conflicting evidence rather than silently suppressing it.
- ERW adaptation is optional and absence of ERW output does not block extraction.

## Validation

- scripts/lint
- scripts/test
- lrh validate

## Dependencies / Order

This depends on proposal adoption and `WI-SF-0002` because evidence records require stable story hashes and paragraph anchors.
