# Work Item: WI-SF-0012

## Summary

Build and run a bounded Worldcon-focused Knight/Novum spike that produces an initial model-backed read on whether the science-fiction analysis system is functional enough to justify a 5-10 story local and/or paid sample and, only after a second explicit approval gate, a 146-story Worldcon-scale sample run.

## Problem / Context

The current `WI-SF-0008` Phase 2 path is scoped as a preregistered feasibility pilot with human annotation, adjudication, audit subsets, and formal gates. That path may still be useful later, but it does not match the immediate Worldcon need: a rapid August 23-24 spike to determine whether the existing Knight/Novum contracts and runners can produce usable story-level outputs and cost estimates before the workstream pauses.

`WI-SF-0006` produced only a no-cost fixture runner; its README states that paid model execution and Phase 2/3 pilots are outside that runner's scope. The repository does already have the needed substrates: science-fiction preparation/contracts/sidecar assembly, unified `LLMBackend` implementations, and prior local-model wiring from `WI-LLM-0074`. This item creates a deliberately narrower, non-validating spike path instead of stretching `WI-SF-0008` beyond the user's immediate intent.

### Duplication search
- In-repo: No existing Knight/Novum Worldcon spike work item or model-backed spike runner was found. Related but not duplicate: `WI-SF-0008` executes a full preregistered Phase 2 pilot with human annotation, while `WI-SF-0006` provides only a fixture/no-cost runner.
- Sibling repos: None identified.
- External libraries: None replace the LCATS-specific Knight/Novum contracts, story-bucket preparation, and sidecar-shaped outputs. Existing provider SDKs should be accessed through the repo's `LLMBackend` abstraction.
- Recommendation: Proceed with a narrow experiment-local spike that extends existing LCATS science-fiction and LLM-backend infrastructure rather than duplicating the full Phase 2 evaluation path.

### Demand search
- Work items: `WI-SF-0008` asks for a later Phase 2 pilot but is too broad for this urgent spike. `WI-LLM-0074` supplies a successful local-model precedent over the 146-story Worldcon sample for genre evidence, not Knight/Novum analysis.
- Proposals: `PROP-LCATS-KNIGHT-NOVUM-ANALYSIS-SIDECAR` requests Knight/Novum analysis, but its later pilot path now appears overbuilt for the immediate Worldcon presentation decision.
- Backlog: `project/design/backlog.md` records a prior mismatch where no inexpensive smoke-test path existed between dry-run/fake output and full real API execution, recommending a cheap bounded real-API validation mode.
- Recommendation: Link this item to `WS-KNIGHT-NOVUM-ANALYSIS` as a corrective spike and do not treat it as satisfying `WI-SF-0008` or the preregistered Phase 2 gate.

## Scope

- Add an experiment-local spike runner or script that uses existing story preparation, Knight/Novum contracts, sidecar assembly, and `LLMBackend` implementations.
- Support a no-cost smoke path first, using a fake backend or local OpenAI-compatible backend, on 2-3 selected stories.
- Support a gated 5-10 story local and/or paid sample for rough cost, latency, and output-quality feasibility after the no-cost smoke path succeeds; any paid backend additionally requires a reviewed manifest, estimated budget, pinned configuration, and explicit approval.
- Support a final explicit approval gate for a 146-story local or paid sample, including selected model/backend, estimated dollar cost, estimated wall-clock time, output root, and stop conditions.
- Produce a short report with go/no-go recommendations for the Worldcon presentation path, whether to pull the trigger on any 146-story sample, and whether to resume, revise, or defer the heavier Phase 2 human-annotation pipeline.

## Required Changes

1. Create `experimental/science_fiction_analysis_trial/run_worldcon_spike.py` or an equivalent experiment-local spike runner.
2. Create `experimental/science_fiction_analysis_trial/manifests/worldcon_spike_manifest.json` with deterministic story selections for 2-3 story smoke, 5-10 story sample, and optional 146-story sample modes.
3. Implement backend selection using existing `lcats.llm` abstractions, including a no-cost fake/local path and optional paid backend paths gated by explicit flags plus a reviewed manifest, estimated budget, and pinned configuration.
4. Emit experiment-local outputs under `experimental/science_fiction_analysis_trial/results/worldcon_spike/` or a caller-provided output root, never under `data/` or `corpora/`.
5. Before any paid run, produce a reviewed approval block or manifest section naming the selected backend/model, pinned configuration, estimated dollar cost, estimated wall-clock time, output root, and stop conditions.
6. Produce `experimental/science_fiction_analysis_trial/worldcon_spike_report.md` summarizing smoke results, 5-10 story sample results, any approved 146-story results, token/cost/latency observations, failures, qualitative usefulness, and a go/no-go recommendation.
7. Add focused tests for manifest loading, staged approval gating, paid-run gating, output-root safeguards, fake/local smoke behavior, output shape, and report generation.

## Non-Goals

- Do not execute or claim completion of `WI-SF-0008`.
- Do not perform human annotation, adjudication, gold-label creation, preregistered gate scoring, or Phase 2 validation.
- Do not run paid model calls without a reviewed manifest, estimated budget, pinned configuration, and explicit human approval after the no-cost smoke path succeeds.
- Do not run the 5-10 story sample before the 2-3 story smoke path has structurally succeeded.
- Do not run the 146-story sample without a second explicit approval of the selected model/backend, estimated dollar cost, estimated wall-clock time, output root, and stop conditions.
- Do not write `science-fiction.json`, `genre.json`, or any other output into corpus buckets or production promotion paths.
- Do not modify `lcats annotate`, `lcats promote`, corpus promotion behavior, or production annotation commands.
- Do not treat local-model agreement or Opus spike output as a final authoritative Knight/Novum interpretation, presentation claim, or production classification.

## Acceptance Criteria

- A bounded experiment-local Knight/Novum spike runner or script can prepare selected stories, call a configured backend, and emit per-story Knight interval and Novum dimension summaries without writing to corpus or promotion paths.
- A no-cost local or fake-backend smoke path runs on 2-3 stories and reports structural success, failures, token counts when available, and output locations.
- A 5-10 story local and/or paid sample runs only after smoke success; any paid backend additionally requires a reviewed manifest, estimated budget, pinned configuration, and explicit approval before execution, and reports estimated and actual token/cost/latency data.
- Any 146-story sample run is a separate final gate requiring explicit approval of the selected model/backend, estimated dollar cost, estimated wall-clock time, output root, and stop conditions.
- Spike outputs include enough evidence snippets, rationale, failures, and cost/latency notes to support a Worldcon go/no-go recommendation without claiming Phase 2 validation or human agreement.
- `scripts/test` and `lrh validate` pass with 0 errors.

## Dependencies / Order

This item depends on `WI-SF-0006` because the spike should reuse the existing experiment-local runner conventions, sidecar assembly, fixture safeguards, and validation shape. It depends on `WI-GENRE-0004` for the current Worldcon-scale sample context, but the full 146-story sample remains behind a second explicit approval gate. It depends on `WI-LLM-0074` only as an implementation precedent for opt-in local backend wiring and reporting discipline.

## Risk Notes

- A local model may pass structural smoke tests while still producing weak literary judgments; this item must distinguish plumbing success from semantic confidence.
- A 5-10 story local and/or paid sample can estimate feasibility but cannot validate accuracy, agreement, or paper-grade claims.
- A 146-story local or paid run may still fail or produce weak outputs at scale; approval must be based on the smoke/sample evidence plus explicit cost and wall-clock estimates, not optimism.
- The compressed Worldcon timeline favors pragmatic outputs over complete sidecar fidelity; the report must document any shortcuts clearly.
- If the spike reveals that prompts or model output are not reliable enough, the correct result is a stop/revise recommendation, not escalation to the 5-10 or 146-story sample.
