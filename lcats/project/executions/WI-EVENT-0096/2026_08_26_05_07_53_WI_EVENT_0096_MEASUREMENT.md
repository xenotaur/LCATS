# Result

Wrote `resolve_baseline_story_list.py` (with 4 unit tests) to resolve
`pilot_stories.jsonl`'s 17 `story_id`s to their current `corpora/`
directories - all 17 resolved unambiguously via `discovery.find_json_files`.
Ran `check_segmentation_reliability.py --story-list ... --model
claude-haiku-4-5-20251001` for real: 17 LLM calls, $0.59 actual cost
(225,626 input / 73,483 output tokens, measured directly from each story's
recorded `usage`, not estimated).

**Result: `parsing_error` structurally eliminated (11/17 -> 0/17)** by
switching to `tool_schema=`, which removes the failing free-text
JSON-parse step. **The any-cause exclusion rate - the only real, measured
comparison - barely moved (65% -> 59%, 11/17 -> 10/17)**, because all 10
new exclusions are `alignment_error` ("anchor text not found in story
text") - the known near-miss-anchor issue `WI-SEGMENT-0069` investigated
and `WI-SEGMENT-0072` evaluated (fuzzy-matching) and declined to fix. One
story (`wintry_peacock_from_the_new_decameron_volume_iii__lawrence`)
flipped from included to excluded; reported as an observed flip, not
asserted as a regression, since a single pre/post-fix call pair at
`temperature=0.2` cannot rule out ordinary model variance. Per-genre:
science fiction unchanged, horror and western improved (western no
longer zero), romance's observed count dropped.

**Review-round correction (this session's own review pass, two P1/P2
findings confirmed real before fixing):** the first draft of this
record's, `SUMMARY.md`'s, and `WI-EVENT-0033.md`'s conclusions treated
the 0/17 `parsing_error` count as measured confirmation of improved
reliability - exactly the tautology this item's own review round (PR

which I then reintroduced in the *conclusion wording*. `parsing_error` is
`None` unconditionally on the `tool_schema` path, so 0/17 is guaranteed

actually measured: the any-cause exclusion-rate comparison. The single-
story flip was also reworded from "regression, not noise" to "observed
flip, not yet established as a regression," since one pre/post-fix call
pair cannot rule out sampling variance at `temperature=0.2`.
