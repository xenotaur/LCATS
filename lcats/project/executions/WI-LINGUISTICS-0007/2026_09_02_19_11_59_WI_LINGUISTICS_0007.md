`WI-LINGUISTICS-0007`: a new experiment-09 harness mirrors the fixed
experiment-05 sample into an experiment-local results tree, generates rich
token-detail-v2 and `linguistics-lexicon-v1` artifacts there, validates the

runtime/storage/projection evidence, and keeps downstream POS/full-corpus
decisions deferred until the human audit is supplied.

# Result

- Added `experiments/09_rich_linguistics_genre_sample/` with a rerunnable,
  resume-safe pilot runner and README. The runner copies the exact
  experiment-05 146-story manifest membership, records source/copy hashes in
  `results/sample_snapshot_manifest.json`, writes `results/story-list.txt`,
  runs the shared linguistics runner with token-detail-v2 and lexicon output,

  `results/experiment_report.json`, `results/linguistics_run_summary.json`,
  `results/pos_audit.json`, and `results/pos_audit_sample.csv`.
- Added a deterministic POS audit protocol with labels `NOUN`, `PROPN`, and
  `OTHER`; combined noun family `NOUN + PROPN`; overall precision/recall gate
  0.90; severe genre-slice threshold 0.80 for genres with at least 10 audited
  rows; and a Stanza-comparison policy that triggers only if the scored spaCy
  audit misses or is inconclusive.
- Fixed a real spaCy compatibility issue discovered by the pilot: token-detail
  validation now accepts UPOS `SPACE`, with a regression test.
- Added an experiment-scoped `parquet_bridge.py` plus tests. It exports the
  generated token-detail JSON to three ZSTD Parquet tables and can restore
  canonical `linguistics.tokens.json`, compact `linguistics.json`, and derived
  `linguistics.lexicon.json` artifacts for existing validators/downstream
  tools. This is intentionally experiment-local; no project-wide dependency or
  canonical storage schema was changed.
- Added proposed follow-on `WI-LINGUISTICS-0009` to design the durable
  project-wide columnar/archival storage policy before any full-corpus rich
  run.
- Added a `.gitignore` rule for
  `experiments/09_rich_linguistics_genre_sample/results/copied_buckets/` so the
  expanded regenerated mirror is not committed; committed evidence remains the
  report/audit metadata plus compact Parquet export.
