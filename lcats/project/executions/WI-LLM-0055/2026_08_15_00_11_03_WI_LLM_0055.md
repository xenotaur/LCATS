# Summary

Implemented `WI-LLM-0055`, which asked the model-comparison benchmark
harness to retain extracted entity identities in `results.json` and add
a comparison tool that can show same-input entity differences across
candidates.

# Result

- Added `BenchmarkResult.entities` in
  `lcats/experimental/model_comparison/common/harness.py`, populated from
  the already-parsed entity extraction tool result while preserving
  `entity_count` for existing summary consumers.
- Added `lcats/experimental/model_comparison/entity_diff.py`, a read-only
  CLI that compares compact entity identities by normalized
  `canonical_name` and displays `entity_type` when present.
- Documented the new `entities` field and diff workflow in
  `lcats/experimental/model_comparison/README.md`.
- Added focused tests for entity-list capture, set-difference output,
  type-display/name-match behavior, and failed/stale result handling.

    than treating it as zero extracted entities.
