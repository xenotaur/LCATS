# Summary

Implemented `WI-GENRE-0076`: append-mode genre-sidecar writes for
`lcats annotate`, teaching it to append new assessments to an existing
`genre-sidecar-v1` sidecar (or convert-then-append a legacy flat one)
instead of overwriting it.

# Result

- `lcats/src/lcats/analysis/corpus/annotate.py`: added
  `merge_genre_sidecar()` (branches on the existing `genre.json`: appends
  to a valid v1 record, converts-then-appends a legacy flat sidecar, or
  wraps a fresh v1 record when nothing valid exists), `build_model_
  genre_assessment()` and `build_human_genre_assessment()` (both sources
  constructible through the same append path), `lcats_story_id()` (the
  `<collection>/<bucket>` lcats_id format matching WI-GENRE-0004's real
  committed evidence), and `_latest_genre_assessment_result()` (used by
  `_write_readme()` to read the current/most-recent assessment's nested
  `result` fields regardless of whether the sidecar on disk is v1 or
  legacy-flat-shaped). `_annotate_genre()` now returns a third
  `from_cache` flag so `annotate_story()` can distinguish a genuinely
  fresh assessment (append it) from a resumed checkpoint-hit replay of
  an already-materialized sidecar (no-op, matching this module's own
  idempotency guarantee).
- Every write goes through `genre_sidecar.validate_sidecar()` before
  being committed; a would-be-invalid merge is refused (existing
  `genre.json` left untouched), not silently overwritten.
- Existing atomic-write convention (`_atomic_write_text`/`_write_json`)
  preserved for the new path; an existing `current_adjudication` pointer
  survives a merge.
- `lcats/tests/analysis_tests/annotate_test.py`: 15 new tests (append to
  valid v1; convert-then-append legacy; fresh write produces valid v1,
  not legacy shape; refuse write on unrecognized existing sidecar;
  checkpoint hit is a no-op, not a duplicate append; `current_
  adjudication` preserved across merge; atomic write on the actual merge
  path; README renders both v1 and legacy shapes; scenes.json unaffected;
  human-assessment constructibility), several replaying `WI-GENRE-0004`'s
  own real committed evidence
  (`experiments/05_metadata_genre_prefilter/results/full_scan/validation_results.jsonl`)
  as fixtures.

  record: `2026_08_22_18_36_36_WI_GENRE_0076_SELFREVIEW`) found and fixed
