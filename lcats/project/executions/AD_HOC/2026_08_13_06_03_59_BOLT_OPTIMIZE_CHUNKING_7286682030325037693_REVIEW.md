# Summary

Address open review comments on PR #216 (⚡ Bolt: Optimize `chunk_story`
character offset calculation). Codex and Copilot both flagged that the
PR's stated fix (replacing `enc.decode(tokens[:start_token])` with a
byte-buffer + cache approach) did not actually achieve O(N) chunking.

# Result

Fixed both comments:

- **Codex** (P2, `discussion_r3701569067`): `current_bytes += enc.decode_bytes(...)`
  copies the entire growing byte buffer on every append (bytes are
  immutable), so the cumulative cost across chunks is still O(N^2).
- **Copilot** (`discussion_r3701572268`, duplicate finding also on line
  73/73): `current_bytes.decode("utf-8", errors="replace")` re-decodes
  the *entire* accumulated buffer on every cache miss, not just the
  newly-appended slice — also O(N^2) overall. Copilot additionally
  suggested guarding `overlap_tokens < max_tokens` to avoid a
  non-positive `step` (infinite loop).

Both were verified present in the diff, valid (the underlying math is
genuinely quadratic, not just a smaller constant factor), and feasible
to fix without changing the function's external behavior. Fix applied
in `lcats/src/lcats/chunking.py`: replaced the byte-buffer + full-redecode
approach with a stateful `codecs` incremental UTF-8 decoder that decodes
each newly-seen token slice exactly once and accumulates a running
character count — genuinely O(N) total decode work, since `start_token`
is provably non-decreasing across iterations. Also added a
`ValueError` guard for `overlap_tokens >= max_tokens` per Copilot's
suggestion.

Added a byte-level fake tokenizer (`FakeByteEncoding` in
`tokenizer_test_utils.py`) — the existing character-level fake tokenizer
can never produce a token whose bytes split a multi-byte character, so
it couldn't exercise this fix's correctness — plus a regression test
(`test_chunk_story_multibyte_boundary_start_char_correct`) that verifies
`start_char` stays correct when a chunk boundary falls mid-character,
and a test for the new `overlap_tokens >= max_tokens` guard.

Nothing skipped.
