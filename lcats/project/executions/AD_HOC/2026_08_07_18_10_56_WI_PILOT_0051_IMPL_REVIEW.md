# Result

- **Segmentation usage lost on unexpected exceptions (Codex P2,
  confirmed valid)**: `run_story()` only preserved `seg_stage_usage` for

  ERW extraction or checkpoint writing) silently dropped that
  already-paid-for cost. Fixed by attaching `usage_rows` to any
  exception raised in that scope and recovering it in `_run_stories`'s
  generic exception handler. Added a regression test proving a
  `RuntimeError` injected during `_run_erw_extraction` still preserves
  the prior segmentation `PassUsage` row.
- **`--story-list` crashes on a directory/unreadable path (Copilot,
  confirmed valid)**: changed `.exists()` to `.is_file()` checks (both
  `--story` and `--story-list`, for consistency) and widened the
  `except ValueError` to `except (ValueError, OSError)`. Added a
  regression test for a directory path.
- **Sentinel string collision (Copilot, confirmed valid)**:
  `_STORY_LIST_DEFAULT_SENTINEL` was a plain string
  (`"__FIXTURES_DEFAULT__"`) that could collide with a real user
  filename. Changed to a distinct `object()` compared via `is`, which
  can never equal a CLI-supplied string. Added a regression test using
  a real manifest file literally named `__FIXTURES_DEFAULT__`.
