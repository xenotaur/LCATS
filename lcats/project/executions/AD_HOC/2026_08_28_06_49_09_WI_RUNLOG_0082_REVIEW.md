   logging `story_skipped` vs `story_downloaded` accordingly (no change
   to `download()`'s own contract needed). Updated the existing
   `test_run_log_records_start_and_per_story_and_end_in_order` and
   `test_crash_mid_run_leaves_a_readable_partial_log` mocks (which
   previously never populated `.downloads`, so would have silently
   always logged `story_skipped` after this fix without the mock
   update) and added a new `test_already_downloaded_story_logs_skipped_not_downloaded`.
4. **P2, real gap: `assess_cli.py`'s final `--format json` write lived
   outside the `RunLog` scope** — a failure serializing the accumulated
   results would have produced a false clean `run_end` instead of
   `run_aborted_unexpected`. Moved the write inside the `with` block, as
   the literal last statement.
5. **P1: `assess_cli_test.py` violated this repo's module-only import
   rule** for LCATS test code (`tests/AGENTS.md`) — imported
   `AssessmentResult` as a bare member instead of importing the `assess`
