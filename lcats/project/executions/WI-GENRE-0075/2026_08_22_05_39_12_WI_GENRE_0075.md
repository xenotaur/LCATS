# Summary

Implemented `WI-GENRE-0075`: a sidecar-tranche promotion mode for
`lcats promote`, unblocking `WI-GENRE-0077` (which depends on this WI).

# Result

- `lcats/src/lcats/analysis/corpus/promote.py`: added
  `promote_sidecar_tranche(manifest_path, dest_root, dry_run=False)`,
  reading a JSONL manifest of `genre-sidecar-v1` records (one per line,
  e.g. `experiments/05_metadata_genre_prefilter`'s own
  `validation_results.jsonl`) and promoting each record's `genre.json`
  into `dest_root/<lcats_id>/genre.json` - nothing else in that story's
  directory or collection is touched. Every record is validated via
  `genre_sidecar.validate_sidecar()` first; invalid records are rejected
  (`SidecarPromotionFinding`) and reported, not written. A legacy flat
  `genre.json` already at the destination (per
  `genre_sidecar.is_legacy_flat_sidecar()`) is refused with a clear
  error, not overwritten - converting one is explicitly `WI-GENRE-0076`'s
  job, not this WI's. Writes go through a new `_atomic_write_text()`
  helper (tempfile + `os.replace`), mirroring `annotate.py`'s own
  existing pattern for the identical failure mode (a torn write on
  interruption).
- `lcats/src/lcats/analysis/corpus/promote_cli.py`: added a
  `--tranche-manifest` flag; when given, `run()` calls
  `promote_sidecar_tranche()` instead of the wholesale path and
  short-circuits before it - `--source`/`collections` are ignored in
  that mode. The existing wholesale invocation and its exit-code/output
  behavior are completely unchanged when the new flag isn't passed.
- `lcats/tests/analysis_tests/promote_test.py`: 10 new tests - clean
  tranche promotion without touching other files; invalid-record
  rejection; legacy-sidecar-at-destination refusal (and that the legacy
  file survives untouched); dry-run makes no writes; a malformed
  manifest line is rejected per-line, not fatal to the whole run; a
  regression check that `promote_collections()` itself is unaffected;
  plus 4 CLI-level tests confirming the new flag actually reaches
  `promote_sidecar_tranche()` (not just the library function called
  directly), reports rejections with a nonzero exit code, respects
  `--dry-run`, and that existing wholesale CLI invocations are
  unaffected.
- A diff-mode `/lrh-self-review` pass before this PR's first push (own
  record: `2026_08_22_05_37_24_WI_GENRE_0075_SELFREVIEW`) found no
  issues - all 7 acceptance criteria independently checked against the
  actual code, tests re-run, `lrh validate` re-run.
