# Summary

Implement `WI-VISUALIZE-0090`: add a genuine group-vs-complement TF-IDF
contrast metric to `lcats visualize tfidf` as a new, additive `--contrast`
mode, closing the gap between `WS-CORPUS-TEXT-VISUALIZATION`'s "comparison
visualizations" exit criterion and `WI-VISUALIZE-0086`'s original
within-group-salience-only delivery.

# Result

- `lcats/src/lcats/visualize/analysis.py`: `tfidf_top_terms` gains a
  `contrast: bool = False` parameter. `contrast=True` computes
  `group_mean - complement_mean` over the same corpus-wide-fit TF-IDF
  matrix; the default (`contrast=False`) path is byte-identical to before.
  Returns `{}` when the complement is empty (whole-corpus group).
- `lcats/src/lcats/visualize/cli.py`: `--contrast` flag on the `tfidf`
  subcommand, validated to require `--genre` (raises a clear `ValueError`
  otherwise); manifest gains an additive `mode` field (`salience`/`contrast`).
- Reused the existing `plot_tfidf_bar_chart` rendering primitive -- no new
  parallel plotting API.
- Dogfooded a real contrast figure (fantasy genre, full 1868-story corpus)
  under `experiments/08_visualize_dogfood/figures/tfidf_contrast_fantasy/`;
  added a "Salience vs. contrast" README section with a real side-by-side
  ranking comparison against the existing `tfidf_fantasy/` figure.
- Updated `lcats/docs/how-to/run-visualize.md` and
  `lcats/docs/reference/cli-commands.md` to document both `tfidf` modes
  accurately without contradiction.
- New tests: contrast-ranking correctness (group-only term ranks above a
  term equally common to group+complement, ranks above a complement-only
  term, using a deterministic hand-computed fixture), the
  `--contrast`-without-`--genre` error path, and confirmation the default
  path is unchanged.
