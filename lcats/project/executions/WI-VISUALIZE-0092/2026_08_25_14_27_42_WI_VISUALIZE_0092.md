# Summary

Implement mirrored-pair and reference-overlay comparative lexical charts, add
the thin `lcats visualize compare` CLI, and ship adjacent CSV/manifest outputs
for the aligned `ComparisonResult` table from `WI-VISUALIZE-0091`.

# Result

- Added reusable mirrored and reference-overlay renderers in
  `src/lcats/visualize/rendering.py`. Renderers consume `ComparisonResult`
  rows/manifest and do not recalculate analysis.
- Added `lcats visualize compare` options for corpus or manifest universes,
  genre selectors, complement/universe references, metrics, vocabulary,
  ordering, token filters, style, output formats, and output directory.
- Added comparison source adapters for joining story text, candidate genres,
  and optional manifest `selection_genre` labels into `ComparisonCorpus`.
- Wrote `comparison.csv` and `comparison_manifest.json` beside generated
  figures, with figure output paths recorded in the manifest.
- Guarded misleading unsupported CLI combinations: primary membership is
  rejected until a per-story primary source exists, selection membership
  requires a manifest, and explicit ordering is rejected until an explicit
  term-list option exists.
- Updated visualize how-to and CLI reference docs.
- Pre-PR multi-agent review found the selection-without-manifest and
  explicit-ordering CLI gaps; both were fixed with regression tests before PR
  creation.
