# Summary

`/lrh-execute WI-RUNLOG-0082` (inlined `/lrh-implement`) — added a
crash-safe, incremental run-event log to `lcats gather`, `lcats assess`,
and `lcats annotate` via the shared `lcats.utils.run_log.RunLog` module —
three CLI commands sharing the same paid/network-loop shape and
previously missing any ordered, human-readable trail of what happened
during a run.

# Result

**`lcats gather`**: `gatherlib.gather()`'s download loop wrapped in a
`RunLog` scope, log path `logs/gather/<corpus>_gather_run_log.jsonl` by
default (outside the protected `data/` tree) — chose the WI's simpler
fixed-directory alternative over threading a new `--log-dir` CLI option
through `main.py` and all ~11 individual gatherer wrapper functions,
since the WI explicitly offered both as equally valid. No new per-story
exception handling added (Non-Goal) — an unhandled `download()` failure
still aborts the whole call, now surfacing as `run_aborted_unexpected`
instead of a bare traceback. `mass_quantities`/`sherlock`/`lovecraft`
(each with their own separate `gather()`) untouched, per the WI.

**`lcats assess`**: new `--log-dir` CLI option on `assess_cli.py`;
omitted, no log is written at all (documented in `--help` — assess has
no other durable working directory to default to). `--dry-run` never
calls `assess_story`, so only `run_start`/`run_end` are logged.

**`lcats annotate`**: `log: Optional[run_log.RunLog] = None` threaded
through `annotate_collections → annotate_collection → annotate_story`
(every existing direct caller unaffected), reusing the existing
`--checkpoint-dir`/`roots` `annotate_cli.py` already resolves.

No changes to any of the 3 commands' checkpoint semantics or output
formats. Added 8 new tests: 2 in `gatherlib_test.py` (event ordering,
crash-mid-run partial log), a brand-new `assess_cli_test.py` (3 tests:
log-dir-omitted no-op, event ordering, dry-run logs no story events), 3
in `annotate_test.py` (per-story event, log-optional backward
compatibility, multi-collection threading), and 1 in `annotate_cli_test.py`
(end-to-end CLI wiring). Also updated 3 pre-existing `gatherlib_test.py`
tests to pass an explicit `log_dir` (a tmp path) — `gather()`'s new
default would otherwise write real files into whatever directory runs
the test suite.

Ran a diff-mode `/lrh-self-review` pass before pushing (Step 7.5) —
clean, no findings; independently re-verified the no-out-of-scope-touches
claim directly via `git diff --stat`.

Opened PR #404 (`xenotaur/feat/wi-runlog-0082`) against `main`.
