# Result

`promote_collections()` wraps both the surveying phase (a list
comprehension calling `survey_collection` for every requested
collection) and the per-collection copy loop in a single `RunLog`
scope, log path `logs/promote/promote_run_log.jsonl` by default
(outside both `--source`/`data/` and `--dest`/`corpora/`, both
protected roots by default). `run_start` carries the full collection
list; `promote_start`/`promote_end` bracket each `_copy_collection`
call; `collection_blocked` fires for mojibake-gated collections with
finding counts; `run_end`/`run_aborted_unexpected` close the run —
`promote.py` has no `FatalPromoteError`/account-level-fatal exception
class, so every uncaught exception (from surveying or `_copy_collection`)
classifies `run_aborted_unexpected`, never left uncategorized.
`_copy_collection`'s own `rmtree`-then-`copytree` mechanics are
byte-for-byte unchanged.

Added a `log_dir: pathlib.Path | None = None` parameter, resolved to
`DEFAULT_PROMOTE_LOG_DIR` **inside the function body** rather than as
the parameter's own default value — since `promote_collections()` has
many existing test call sites across 4 different test classes (unlike
`gatherlib.gather()`'s 3), the lazy-default pattern lets
`unittest.mock.patch.object(promote, "DEFAULT_PROMOTE_LOG_DIR", <tmp>)`
in each class's `setUp()` cover every call site in that class, instead
of touching each one individually with an explicit `log_dir=` override.

Added 3 new tests to `promote_test.py` (event ordering on a clean run,
blocked-collection logs `collection_blocked` not `promote_start`/`_end`,
crash-mid-copy leaves a readable partial log with the correct
`promote_start`/`promote_end` counts and terminal
`run_aborted_unexpected`), and updated `PromoteCollectionsTest`,
`PromoteCliTest`, one test in `PromoteSidecarInsertUpsertTest`, and
`gather_promote_e2e_test.py`'s `TestGatherThenPromoteEndToEnd` class so
none of them leak real files into the real default `logs/promote/`
directory.

Ran a diff-mode `/lrh-self-review` pass before pushing (Step 7.5) —
clean, no findings (caught and corrected my own stale-local-`main`
