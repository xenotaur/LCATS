The seven approve/exclude judgments resolve intent for these seven inputs only.
Exclude is an audit disposition: existing gather still reports needs_review and
no collection membership or canonical file changes occur. Defer is investigated,
not resolved. A separate mechanism/decision would be needed for reviewed interior
editorial removal; this tranche does not introduce arbitrary deletion recipes.

Machine-checked source anchors use offsets in the exact decompressed UTF-8 string,
including original CRLF where present. Candidate selections use normalized candidate
Unicode offsets. These two coordinate systems must not be conflated. The source
excerpts and identity-bound dispositions live alongside this rationale.
